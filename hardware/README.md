# ThermoScan Hardware

This directory contains the hardware design files for the ThermoScan system. The device scans photovoltaic panels to collect thermal and electrical measurements and supports localized cleaning when a hotspot is detected.

## Main components

- ESP32 microcontroller.
- MLX90640 thermal sensor.
- Voltage and current sensors.
- Stepper motor for moving the scanning module.
- Water pump and servo motor for targeted cleaning.
- Power supply and control circuits.

Electrical schematics, PCB files, and 3D models can be stored here as they are developed. The ESP32 code is located in the `firmware/` directory.
