# TermoScan App

Mobile application for the TermoScan system. It allows users to register and configure photovoltaic modules, view thermal and electrical measurements, and follow hotspot detection and cleaning events.

## Main features

- Sign in and access modules according to user permissions.
- Register and configure photovoltaic modules.
- View the latest measurements and measurement history.
- View thermal maps and cleaning history when available.
- Receive alerts about issues that need attention.

The app communicates with cloud services to access module data sent by the embedded device.
