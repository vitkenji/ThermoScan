# TermoScan Backend

This directory contains the backend for the TermoScan system. It connects the mobile app and embedded devices, stores module data and measurements, and manages user access.

## Main responsibilities

- Authenticate users and manage their permissions.
- Store photovoltaic module configurations.
- Receive thermal and electrical measurements from embedded devices.
- Provide measurement and cleaning history to the app.
- Manage alerts for issues that need attention.
